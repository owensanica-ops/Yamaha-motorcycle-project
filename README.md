# Yamaha-motorcycle-project
### This will feature the development and production of my dream motorcycle (Yamaha r7 2026 addition) out of pure passion and wanted experience.

### Plan
- Determine the functionality of the engine
- Design the engine
- Design the motorcycle
- Complete pitch deck for investors and grants
- Buy materials
- Find a place to assemble
- Trial and error
- Final product

### Progress
I decided that the motorcycle was going to be hydrogen fueled and had to take into consideration of the fact that the motorcycle would affect the look of the motorcycle. The motorcycle was originally going to be electric and inspired of off the Yamaha r7 ( It still will be) but knowing that the engine would effect the shape it makes more sense to worry about the engine first.

Doing some research, I found that MIT (Massachusetts Institute of Technology) actually made a hydrogen fueled motorcycle as a project so during this project I will be referencing from that same project.
